# 飞书多维表格「快递查询助手」字段捷径

本仓库维护飞书多维表格 **「快递查询助手」** 字段捷径的 FaaS 源码、测试和本地预览。在表格中录入快递单号后，可查询物流轨迹并结构化回填。物流查询后端单独部署，不包含在本仓库中。

---

## ✨ 核心特性（对齐飞书字段捷径中心标准）

1. 🚀 **全自动智能识别主流承运商**
   - 自动识别快递单号前缀，无需手动指定快递公司。
   - 深度覆盖顺丰速运、京东物流、三通一达（圆通、中通、申通）、韵达速递、极兔速递、中国邮政、EMS、德邦快递、安能物流、跨越速运等上百家主流快递物流公司。

2. 🔒 **完整手机号随运单查询**
   - 顺丰（SF）、中通（ZTO）、跨越速运（KYE）等需要手机号的运单，使用表格中填写的完整 11 位收/寄件人手机号。
   - 缺少手机号或仅填尾号、脱敏号等格式错误的值时，在请求前提示补填。格式正确的手机号与运单号一同提交给阿里云快递接口，由接口判断能否查询该运单；本地不根据轨迹中的手机号片段判断是否匹配。

3. 📊 **多维表格结构化数据全量回填**
   - 输出完整 Object 对象，包含：
     - `summary`（物流摘要）：单元格主显示，如 `顺丰速运 · 已签收 · 您的快件已由前台代收`
     - `trackingNumber`（快递单号）
     - `carrier`（快递公司名称）
     - `carrierCode`（承运商英文缩写，如 SF、JD、YTO）
     - `status`（物流状态，如 在途、派件中、已签收、已揽收、待补全手机号、暂无轨迹）
     - `latest`（最新轨迹描述）
     - `queriedAt`（查询时间，标准时间格式）
     - `trace`（按时间倒序排列的完整轨迹明细）
   - 用户可利用飞书多维表格的“引用子字段”功能，一键提取任意属性用于看板、自动化通知流。

4. 🔄 **自动更新**
   - 默认不定时查询；保留字段的「自动更新」时，新增或修改单号、手机号会重新查询。
   - 需要定时查询时，按[配置说明](./帮助文档-快递查询助手.md)绑定日期触发列并手动启用飞书工作流。每日建议 08:00（北京时间，可改）；如工作流支持所需的自定义频次，可按 30 分钟的整数倍运行。
   - 单号、手机号和定时更新的配置说明会提示如何新建字段，或在已选字段被删除后重新创建并选择。

5. 💳 **额度归属**
   - 正式 `/field/api/express/query` 不读取、不初始化、不扣减与边栏共用的 `platform_license`；字段捷径查询额度由飞书平台统一管理。生产部署需配置 `FIELD_FEISHU_PACK_IDS` 验证飞书签名。
   - 边栏插件继续使用自己的额度校验和扣减逻辑。两条入口虽然共用数据库，但字段捷径不会改动边栏的额度记录。

## 字段捷径上架效果模拟页

```sh
npm run field:mock
```

打开 `http://127.0.0.1:8790/`，可以查看接近飞书上架后配置弹窗的效果。页面包含字段配置、生成范围、输出字段、自动更新，以及可选的每日时间和 30 分钟倍数间隔。

勾选「每日定时」或「按间隔」，设置后点击「保存时间」或「保存间隔」，按钮会显示「保存成功」。设置只保存在当前浏览器中，不会连接飞书、不创建工作流、不查询物流。正式字段捷径的配置由飞书渲染，实际定时任务仍需要飞书工作流触发日期字段。

## 🛠️ 本地开发与测试

要求 Node.js `>= 14.16.0`。

```sh
# 安装依赖
npm install

# 运行自动化单元测试
npm test

# 编译 TypeScript
npm run build

# 本地热重载实时调试（多维表格通过“字段捷径开发助手”连接 127.0.0.1 体验）
npm start
```

## 📦 打包与上架

```sh
npm run pack
```

打包产物将自动生成在 `output/` 目录下（如 `output/output_*.zip`）。只上传该 zip；图标、封面、概述和字段捷径中心的付费方案在中心管理页面单独维护，不在代码 zip 中。

当前版本的 `block-basekit-cli pack:field` 会先清空 `output/`。需要保留的历史发布包请先复制到其他目录，再运行打包命令。

当前包不声明任何用户授权项，不会因代码包要求用户关联阿里云账号。查询由宝塔服务端处理，AppCode 只放在服务器 `.env` 的 `ALIYUN_EXPRESS_APPCODE`。若飞书拒绝用此包更新已有捷径，说明旧授权项不允许在原商品上移除，应把当前包用于新建商品；已添加的旧字段可能还保留原配置，需要重新添加无授权版字段。

当前字段捷径查询接口为 `https://express-delivery.anhuishuzhi.com/field/api/express/query`。本次额度切换需要配合更新 FaaS 和字段后端，顺序见 [`字段捷径额度切换部署说明.md`](./release/字段捷径额度切换部署说明.md)。后端补丁不能作为字段捷径代码包上传。

后端补丁、上架素材和真实凭据不随源码入库。`server` 与 `server:install` 脚本只适用于另有本地独立后端源码的开发环境。

## 🌐 安全域名与合规配置

在飞书开放平台后台安全设置与域名白名单中，添加：
- `express-delivery.anhuishuzhi.com`（额度与物流查询服务）

阿里云 AppCode 只配置在后端环境变量 `ALIYUN_EXPRESS_APPCODE`，用户添加字段捷径时无需填写。

本地预览使用 `127.0.0.1`；正式物流查询需要飞书云端可访问的 HTTPS 后端。字段捷径的购买和查询额度以飞书字段捷径中心为准。
